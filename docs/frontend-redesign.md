# Code Guardian 前端重构 - 使用 Taste Skill 高审美设计

## 重构概述
本次重构基于 Cola Skill Hub 的 `taste-skill` 安装并遵循其设计原则，对 Code Guardian 项目的前端界面进行了全面优化，目标是实现高端、有品味、无 AI 味的专业级界面。

## 核心设计原则应用

### 1. 色彩系统重构
- **完全摒弃 AI 常见紫/蓝渐变**：替换为专业的 Zinc/Slate 中性色系统
- **单一强调色采用 Emerald 绿**：避免多色混用，保持视觉统一
- **语义色彩克制化**：高危/中危/低危使用更专业的色调而非刺眼警示色
- **深色模式专业适配**：保持同样专业感，避免简单反色

### 2. 字体排版优化
- **采用高端无衬线字体栈**：Geist、Satoshi、Outfit、Cabinet Grotesk 等专业字体
- **禁用 Inter 字体**：符合 Taste Skill 反常规要求
- **提升基础字体大小**：16px 提升可读性
- **优化行高和字间距**：1.7 行高，适当字间距调整提升阅读体验

### 3. 布局与结构创新
- **非对称 Hero 区域**：摒弃居中布局，采用 3:2 比例分屏结构
- **卡片容器升级**：使用更精致的圆角、悬浮阴影和交互反馈
- **表单元素重构**：专注状态、聚焦状态和禁用状态的细致处理
- **数据可视化重构**：风险仪表盘、状态步骤指标等采用更专业的展示形式

### 4. 动效与交互细节
- **悬浮微交互**：按钮、卡片等元素添加细微位移和颜色变化
- **加载状态优化**：使用骨架屏和专业加载指示器
- **状态反馈明确**：成功、警告、错误状态使用专业色块和图标
- **过渡动画平滑**：所有状态变化使用 200ms 过渡时间

### 5. 组件库重构
- **统一设计语言**：所有 UI 组件遵循相同的设计原则
- **可组合变体**：按钮提供 primary/destructive/outline/secondary/ghost/link 等变体
- **响应式适配**：在不同断点下保持专业布局和可读性
- **深色模式支持**：完整适配深色模式，保持专业一致性

### 6. 性能与可访问性
- **减少不必要的重渲染**：使用 React.memo 和 useCallback 优化
- **键盘友好**：所有交互元素支持键盘操作
- **屏幕阅读器支持**：适当的 ARIA 属性和语义化 HTML
- **聚焦管理**：清晰的焦点可见状态和焦点顺序

## 关键设计决策说明

### 为什么选择 Emerald 绿作为主色？
- 避免 AI 常见的紫/蓝配色（Taste Skill 明确禁用）
- 绿色在技术领域代表安全、增长和专业性
- Emerald 绿提供足够的鲜艳度而不失专业感
- 在深色模式下保持良好对比度

### 为什么采用非对称布局？
- 摒弃 AI 常见的居中套路（Taste Skill 明确要求）
- 创造动态视觉张力，引导用户视线流动
- 更好地利用宽屏空间，提升信息密度控制
- 符合现代专业网站设计趋势

### 如何确保“无 AI 味”？
- 避免所有常见 AI 设计套路：居中布局、紫色渐变、过大头像、通用图标
- 使用专业级色彩搭配和排版规则
- 注重细节处理：悬浮状态、加载反馈、错误处理等
- 采用专业字体而非系统默认或通用免费字体
- 保持适当的信息密度和留白平衡

## 后续维护建议

1. **保持色彩系统纯净**：新增颜色必须通过设计审查，避免引入 AI 常见色彩
2. **字体使用纪律**：继续使用专业字体栈，避免回退到系统字体
3. **组件扩展规范**：新增 UI 组件必须遵循既定的设计语言和变体模式
4. **交互细节把握**：保持悬浮、按下、焦点等交互状态的一致性处理
5. **定期设计审计**：每季度检查是否有 AI 常见设计套路回潮
