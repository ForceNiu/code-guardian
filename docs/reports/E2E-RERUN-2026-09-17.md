### 🔴 本轮踩到的两个操作坑（都已定位，与产品无关）

1. **SSE 抓不到 `parsing/analyzing`** —— 原因不是产品缺陷，而是**「创建任务」与「挂 `curl -N`」被拆成了两次工具调用**，
   中间隔了十几秒，早期阶段已经过去。两次失败（`sse-R1.txt` / `sse-R1b.txt` 只抓到 `connected` / `reporting→done`）。
   ✅ **正解**：把「创建任务 → 起 curl → `sleep` 撑住父 shell」写进**同一条命令**（`sse-R1c.txt` 一次成功）。
   用 `(curl … &)` 子 shell 则会在命令返回时被回收。
2. **`echo "$JSON"` 会毁掉 JSON** —— 本机 zsh 的 `echo` **解释反斜杠转义**，
   把 JSON 字符串里的 `\n` 变成真换行 → 文件损坏（`JSON.parse` 报 `Bad control character`）。
   ✅ **正解**：落盘一律 `curl -o <file>` 或 `printf '%s'`，**永不 `echo "$JSON" > file`**。
